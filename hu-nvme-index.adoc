= NVMe-oF를 사용하여 ONTAP SAN 호스트를 구성하는 방법에 대해 알아보세요
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
지원되는 SAN 호스트를 구성하여 ONTAP 스토리지 대상으로 사용하는 NVMe-oF(NVMe over Fabrics) 프로토콜을 사용할 수 있습니다. NVMe-oF에는 NVMe/FC(NVMe over Fibre Channel)와 NVMe/TCP(NVMe over TCP)가 포함됩니다. 호스트 운영 체제(OS) 및 ONTAP 버전에 따라 호스트 OS에서 NVMe/FC 또는 NVMe/TCP 프로토콜, 또는 둘 다를 구성하고 유효성을 검사합니다.
