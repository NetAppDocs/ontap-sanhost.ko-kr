= FCP 및 iSCSI를 사용하여 ONTAP SAN 호스트를 구성하는 방법에 대해 알아보십시오.
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
특정 SAN 호스트 운영 체제(OS)에서 ONTAP 대상으로 FCP 및 iSCSI를 구성할 수 있습니다. 호스트 OS가 SAN 호스트 유틸리티 소프트웨어에서 지원되는 경우, 먼저 SAN 툴킷이 포함된 해당 OS 호스트 유틸리티 패키지를 설치해야 합니다. 그런 다음 모든 호스트 OS 유형에 대해 ONTAP LUN의 다중 경로 설정을 구성합니다.
